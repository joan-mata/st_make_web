🏗️ Arquitectura MVC

MVC (Model-View-Controller) es un patrón de diseño que separa la aplicación en tres capas independientes, haciendo el código más organizado, mantenible y escalable.

1. ¿Qué es MVC y qué problema resuelve?

Imagina que tienes un archivo PHP de 500 líneas donde se mezcla la consulta a la base de datos, la lógica del negocio y el HTML de la página. Esto se llama "código espagueti": todo enredado, imposible de mantener o ampliar.

MVC propone dividir ese caos en tres responsabilidades claras:

  • Model (Modelo): gestiona los datos y la lógica del negocio. Habla con la base de datos.
  • View (Vista): presenta los datos al usuario. Solo genera HTML.
  • Controller (Controlador): es el intermediario. Recibe peticiones, llama al modelo y elige la vista.
📌 La regla de oro del MVC El Modelo no sabe nada del HTML. La Vista no hace consultas a la BD. El Controlador no tiene HTML ni SQL directos. Cada capa hace una sola cosa.

3. El Modelo (Model)

El Modelo es la capa que gestiona los datos de la aplicación. Sus responsabilidades son:

  • Realizar consultas a la base de datos (SELECT, INSERT, UPDATE, DELETE).
  • Validar los datos antes de guardarlos.
  • Contener la lógica del negocio (reglas de la aplicación).
  • No debe generar HTML ni saber cómo se va a mostrar la información.

4. La Vista (View)

La Vista es la capa de presentación. Sus responsabilidades son:

  • Recibir datos (normalmente variables PHP) y presentarlos en HTML.
  • No tomar decisiones de negocio ni hacer consultas a la BD.
  • Puede tener lógica mínima de presentación (bucles foreach para listar, if para mostrar/ocultar).
  • Un archivo de vista por cada "pantalla" de la aplicación.

5. El Controlador (Controller)

El Controlador es el director de orquesta. Sus responsabilidades son:

  • Recibir la petición HTTP del usuario.
  • Llamar al Modelo para obtener o modificar datos.
  • Pasar los datos obtenidos a la Vista.
  • No debe contener HTML ni SQL directamente.

7. Ejemplo completo: listar usuarios

Vamos a construir la funcionalidad de "listar todos los usuarios" siguiendo el patrón MVC. Necesitamos cuatro archivos:

config/database.php — Conexión PDO

⚠️ Nunca pongas contraseñas en el código Las credenciales de la base de datos deben leerse de variables de entorno, nunca escritas directamente en el archivo. Consulta la guía de Seguridad para ver cómo hacerlo correctamente. 
<?php
// config/database.php
// Devuelve una conexión PDO a PostgreSQL.
// Las credenciales se leen de variables de entorno (.env),
// NUNCA se escriben directamente aquí. Ver guía de Seguridad.

function getDBConnection(): PDO {
    // getenv() lee las variables definidas en el entorno del servidor
    $host   = getenv('DB_HOST') ?: 'localhost';
    $port   = getenv('DB_PORT') ?: '5432';
    $dbname = getenv('DB_NAME') ?: 'mi_proyecto';
    $user   = getenv('DB_USER') ?: 'postgres';
    $pass   = getenv('DB_PASSWORD') ?: '';

    try {
        $dsn = "pgsql:host=$host;port=$port;dbname=$dbname";
        $pdo = new PDO($dsn, $user, $pass, [
            PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
            PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        ]);
        return $pdo;

    } catch (PDOException $e) {
        error_log("Error de conexión DB: " . $e->getMessage());
        die("Error de conexión a la base de datos.");
    }
}

models/User.php — El Modelo

<?php
// models/User.php
// El Modelo gestiona los datos de los usuarios.
// NO sabe nada de HTML.

require_once __DIR__ . '/../config/database.php';

class User {

    private PDO $pdo;

    // El constructor obtiene la conexión a la BD
    public function __construct() {
        $this->pdo = getDBConnection();
    }

    // Obtener todos los usuarios
    public function getAll(): array {
        $stmt = $this->pdo->query("SELECT id, nombre, email, created_at FROM usuarios ORDER BY nombre");
        return $stmt->fetchAll(); // Devuelve array de arrays asociativos
    }

    // Obtener un usuario por su ID
    public function getById(int $id): array|false {
        $stmt = $this->pdo->prepare("SELECT * FROM usuarios WHERE id = :id");
        $stmt->execute([':id' => $id]);
        return $stmt->fetch(); // Devuelve un array o false si no existe
    }

    // Crear un nuevo usuario
    public function create(string $nombre, string $email, string $password): int {
        $hash = password_hash($password, PASSWORD_BCRYPT);
        $stmt = $this->pdo->prepare(
            "INSERT INTO usuarios (nombre, email, password_hash)
             VALUES (:nombre, :email, :password_hash)
             RETURNING id"
        );
        $stmt->execute([
            ':nombre'        => $nombre,
            ':email'         => $email,
            ':password_hash' => $hash
        ]);
        return (int)$stmt->fetchColumn(); // Devuelve el ID generado
    }

    // Actualizar un usuario
    public function update(int $id, string $nombre, string $email): bool {
        $stmt = $this->pdo->prepare(
            "UPDATE usuarios SET nombre = :nombre, email = :email
             WHERE id = :id"
        );
        return $stmt->execute([
            ':nombre' => $nombre,
            ':email'  => $email,
            ':id'     => $id
        ]);
    }

    // Eliminar un usuario
    public function delete(int $id): bool {
        $stmt = $this->pdo->prepare("DELETE FROM usuarios WHERE id = :id");
        return $stmt->execute([':id' => $id]);
    }
}

controllers/UserController.php — El Controlador

<?php
// controllers/UserController.php
// El Controlador recibe la petición, llama al Modelo y carga la Vista.
// NO contiene HTML ni SQL.

require_once __DIR__ . '/../models/User.php';

class UserController {

    private User $userModel;

    public function __construct() {
        $this->userModel = new User();
    }

    // Acción: listar todos los usuarios
    public function index(): void {
        // 1. Llamar al Modelo para obtener datos
        $usuarios = $this->userModel->getAll();

        // 2. Pasar los datos a la Vista
        // La vista puede acceder a $usuarios
        require __DIR__ . '/../views/users/list.php';
    }

    // Acción: mostrar formulario de creación
    public function create(): void {
        require __DIR__ . '/../views/users/create.php';
    }

    // Acción: procesar el formulario de creación
    public function store(): void {
        if ($_SERVER['REQUEST_METHOD'] !== 'POST') {
            header('Location: /index.php?action=create');
            exit;
        }

        $nombre   = trim($_POST['nombre']   ?? '');
        $email    = trim($_POST['email']    ?? '');
        $password = $_POST['password'] ?? '';

        // Validación
        $errores = [];
        if (empty($nombre)) $errores[] = "El nombre es obligatorio";
        if (!filter_var($email, FILTER_VALIDATE_EMAIL)) $errores[] = "Email no válido";
        if (strlen($password) < 8) $errores[] = "Contraseña mínimo 8 caracteres";

        if (!empty($errores)) {
            // Volver al formulario con los errores
            require __DIR__ . '/../views/users/create.php';
            return;
        }

        // Llamar al Modelo para guardar
        $id = $this->userModel->create($nombre, $email, $password);

        // Redirigir al listado
        header('Location: /index.php?action=index&created=1');
        exit;
    }

    // Acción: eliminar usuario
    public function delete(): void {
        $id = (int)($_GET['id'] ?? 0);

        if ($id <= 0) {
            header('Location: /index.php');
            exit;
        }

        $this->userModel->delete($id);
        header('Location: /index.php?action=index&deleted=1');
        exit;
    }
}

index.php — El Router (Front Controller)

<?php
// index.php — Router principal
// Todas las peticiones pasan por aquí
// URL: /index.php?action=index  → muestra la lista
// URL: /index.php?action=create → muestra el formulario

require_once 'controllers/UserController.php';

// Obtener la acción de la URL (por defecto: index)
$action = $_GET['action'] ?? 'index';

// Instanciar el controlador
$controller = new UserController();

// Enrutar a la acción correcta
switch ($action) {
    case 'index':
        $controller->index();
        break;
    case 'create':
        $controller->create();
        break;
    case 'store':
        $controller->store();
        break;
    case 'delete':
        $controller->delete();
        break;
    default:
        // 404: acción no encontrada
        http_response_code(404);
        echo "<h1>404 — Página no encontrada</h1>";
}

8. Flujo completo de una petición

📌 Ejemplo: el usuario visita http://localhost/index.php?action=index
  1. Browser → index.php
    El navegador hace una petición HTTP GET a /index.php?action=index.
  2. index.php (Router)
    Lee $_GET['action'] = 'index', instancia UserController y llama a $controller->index().
  3. UserController::index() (Controller)
    Llama a $this->userModel->getAll() para obtener los datos.
  4. User::getAll() (Model)
    Ejecuta SELECT * FROM usuarios contra PostgreSQL y devuelve un array de usuarios.
  5. Controller (de vuelta)
    Recibe el array $usuarios y hace require 'views/users/list.php'.
  6. views/users/list.php (View)
    PHP itera sobre $usuarios con foreach y genera el HTML de la tabla.
  7. HTML → Browser
    El servidor envía el HTML generado al navegador, que lo muestra al usuario.

9. Buenas prácticas

  • Un archivo por clase: User.php contiene solo la clase User.
  • Nombres descriptivos: UserController, no UC ni Controller1.
  • Separación estricta: si estás poniendo SQL en una Vista o HTML en un Modelo, algo está mal.
  • Redirigir tras POST: siempre redirigir después de procesar un formulario (Post/Redirect/Get pattern).
  • Validar en el Controlador: valida los datos de entrada antes de pasarlos al Modelo.
  • Prepared statements siempre: el Modelo nunca debe concatenar variables en SQL.
