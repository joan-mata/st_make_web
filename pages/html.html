🌐 HTML

HTML (HyperText Markup Language) es el lenguaje que define la estructura y el contenido de cualquier página web. Sin HTML no existe la web.

1. ¿Qué es HTML?

HTML es un lenguaje de marcado, no un lenguaje de programación. No tiene lógica (bucles, condiciones…); simplemente describe qué hay en la página: un título, un párrafo, una imagen, un formulario…

El navegador lee el archivo HTML y lo convierte en la pantalla visual. Cada elemento se define con etiquetas de la forma <etiqueta>contenido</etiqueta>.

📌 Dato clave HTML fue creado por Tim Berners-Lee en 1989 como base de la World Wide Web. La "H" de HyperText hace referencia a los hipervínculos que conectan documentos.

2. Estructura básica de un documento HTML

Todo documento HTML válido debe tener esta estructura mínima. Guárdalo como index.html y ábrelo en el navegador.

Código

<!DOCTYPE html>
<html lang="es">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>Mi Primera Página</title>
    <link rel="stylesheet" href="estilos.css">
  </head>
  <body>
    <h1>¡Hola, mundo!</h1>
    <p>Esto es un párrafo.</p>
  </body>
</html>

3. index.html — La página de entrada

Cuando alguien visita tu web (por ejemplo http://servidor.uab.cat/tu-carpeta/), el servidor busca automáticamente un archivo llamado index.html (o index.php) en esa carpeta y lo sirve como página principal. No hace falta indicarlo en la URL — el servidor lo encuentra solo.

📌 ¿Por qué se llama index? Es una convención histórica: el fichero índice de un directorio. Todos los servidores web (Apache, Nginx…) buscan este nombre por defecto. Si no existe, el servidor puede mostrar un error 403 o listar los archivos del directorio.

Estructura típica de un proyecto sencillo:

Estructura de archivos

mi-proyecto/
├── index.html        ← página principal
├── about.html        ← página "Sobre nosotros"
├── contacto.html     ← página de contacto
├── css/
│   └── estilos.css
└── img/
    └── logo.png

Cómo enlazar entre páginas

Desde index.html:

← estás aquí (index.html) about.html contacto.html

Los links son relativos: no hacen falta rutas absolutas.

Para navegar entre páginas usa el atributo href con la ruta relativa:

<!-- Desde index.html, enlazar a about.html (misma carpeta) -->
<a href="about.html">Sobre nosotros</a>

<!-- Enlazar a un archivo en una subcarpeta -->
<a href="pages/contacto.html">Contacto</a>

<!-- Subir una carpeta y luego entrar en otra -->
<a href="../index.html">Volver al inicio</a>

<!-- Enlace a una sección dentro de la misma página (ancla) -->
<a href="#contacto">Ir a contacto</a>
<!-- ... más abajo en el mismo archivo: -->
<h2 id="contacto">Contacto</h2>
✅ ¿Cuándo pasar de index.html a index.php? Mientras tu página sea estática (solo muestra información fija), usa .html. En el momento que necesites lógica de servidor — procesar formularios, consultar la base de datos, mostrar datos dinámicos — renombra el archivo a index.php y empieza a usar PHP. El servidor ejecutará el código PHP antes de enviar el HTML al navegador. Ver guía de PHP para más detalles.

4. Títulos y párrafos

HTML tiene 6 niveles de títulos (h1 a h6). Usa h1 solo una vez por página (es el título principal). Los párrafos van dentro de <p>.

Código

<h1>Título principal (solo uno)</h1>
<h2>Sección</h2>
<h3>Subsección</h3>
<h4>Nivel 4</h4>

<p>Primer párrafo de texto.</p>
<p>Segundo párrafo. <strong>Negrita</strong>
   y <em>cursiva</em>.</p>

5. Enlaces e imágenes

Código

<!-- Enlace a otra página -->
<a href="about.html">Sobre nosotros</a>

<!-- Enlace externo (se abre en nueva pestaña) -->
<a href="https://ejemplo.com" target="_blank"
   rel="noopener">Visitar ejemplo.com</a>

<!-- Imagen local -->
<img src="fotos/portada.jpg"
     alt="Descripción de la imagen"
     width="300">

<!-- Imagen con enlace -->
<a href="galeria.html">
  <img src="miniatura.jpg" alt="Ver galería">
</a>

7. Tablas

Las tablas muestran datos tabulares (no uses tablas para hacer layout — para eso usa CSS Flexbox/Grid).

Código

<table>
  <!-- Cabecera -->
  <thead>
    <tr>
      <th>Nombre</th>
      <th>Edad</th>
      <th>Ciudad</th>
    </tr>
  </thead>
  <!-- Cuerpo -->
  <tbody>

    </tr>

8. Formularios

Los formularios recogen datos del usuario y los envían al servidor. El atributo action indica el archivo PHP que los procesa, y method el método HTTP (GET o POST).

Código

<form action="procesar.php" method="POST">

  <!-- Campo de texto -->
  <label for="nombre">Nombre:</label>
  <input type="text" id="nombre" name="nombre"
         placeholder="Tu nombre" required>

  <!-- Campo email -->
  <label for="email">Email:</label>
  <input type="email" id="email" name="email"
         placeholder="correo@ejemplo.com" required>

  <!-- Contraseña -->
  <label for="pass">Contraseña:</label>
  <input type="password" id="pass" name="pass">

  <!-- Selector -->
  <label for="ciudad">Ciudad:</label>
  <select id="ciudad" name="ciudad">
    <option value="">-- Elige --</option>
    <option value="bcn">Barcelona</option>
    <option value="mad">Madrid</option>
  </select>

  <!-- Área de texto -->
  <label for="msg">Mensaje:</label>
  <textarea id="msg" name="msg" rows="3"
            placeholder="Escribe aquí..."></textarea>

  <!-- Botón de envío -->
  <input type="submit" value="Enviar">

</form>

Vista previa

📌 GET vs POST Usa method="GET" para búsquedas (los datos van en la URL). Usa method="POST" para enviar datos sensibles o crear/modificar recursos (los datos van en el cuerpo de la petición, no visibles en la URL).

9. div y span — Contenedores genéricos

<div> es un contenedor de bloque (ocupa toda la línea). <span> es un contenedor en línea (solo ocupa lo que necesita). Se usan cuando ningún elemento semántico encaja.

Código

<!-- div: agrupa elementos para darles estilo -->
<div class="tarjeta">
  <h3>Título de la tarjeta</h3>
  <p>Descripción de la tarjeta.</p>
</div>

<!-- span: estiliza parte de un texto -->
<p>
  El precio es
  <span style="color:red; font-weight:bold;">
    24,99 €
  </span>
  (IVA incluido).
</p>

10. HTML Semántico

HTML5 introdujo etiquetas con significado. En lugar de usar <div> para todo, usa el elemento que describe mejor lo que contiene. Mejora el SEO y la accesibilidad.

Código

<body>

  <!-- Cabecera del sitio (logo, nav) -->
  <header>
    <nav>
      <a href="/">Inicio</a>
      <a href="/about">Sobre nosotros</a>
    </nav>
  </header>

  <!-- Contenido principal -->
  <main>

    <!-- Sección temática -->
    <section>
      <h2>Últimas noticias</h2>

      <!-- Contenido independiente (artículo) -->
      <article>
        <h3>Título del artículo</h3>
        <p>Contenido del artículo...</p>
      </article>
    </section>

    <!-- Contenido secundario -->
    <aside>
      <h3>Relacionados</h3>
    </aside>

  </main>

  <!-- Pie de página -->
  <footer>
    <p>&copy; 2025 Mi Sitio Web</p>
  </footer>

</body>

11. Buenas prácticas en HTML

  • Siempre incluye <!DOCTYPE html> al inicio.
  • Usa el atributo lang en <html>.
  • Siempre incluye alt en las imágenes.
  • Usa etiquetas semánticas en lugar de <div> para todo.
  • Usa charset="UTF-8" para soporte de acentos.
  • Los nombres de archivos y carpetas: minúsculas, sin espacios, sin acentos (sobre-nosotros.html, no Sobre Nosotros.html).
  • Indentar el código con 2 o 4 espacios consistentemente.
  • Nunca uses HTML para dar estilo (atributos color, bgcolor, align son obsoletos — usa CSS).
  • Valida tu HTML con el validador oficial: validator.w3.org
✅ Regla de oro HTML = qué es la información. CSS = cómo se ve. JavaScript = qué hace. Mantener esta separación de responsabilidades hace el código mucho más fácil de mantener.
