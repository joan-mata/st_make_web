🐘 PHP

PHP (PHP: Hypertext Preprocessor) es un lenguaje de programación del lado del servidor. El servidor ejecuta el código PHP y devuelve HTML al navegador. El usuario nunca ve el código PHP.

1. ¿Qué es PHP?

Cuando un usuario visita una URL como https://miweb.com/perfil.php, el servidor web (Apache, Nginx…) ejecuta el archivo PHP, que puede acceder a la base de datos, leer archivos, procesar formularios… y al final genera HTML que se envía al navegador.

PHP puede mezclarse con HTML en el mismo archivo, o puede generar respuestas JSON para APIs que consume JavaScript. Potencia el 77% de los sitios web del mundo (WordPress, Wikipedia, Facebook en sus inicios, etc.).

📌 En esta asignatura El servidor ya está configurado en la UAB. Conéctate por SSH con VS Code (Remote - SSH) y edita tus archivos directamente en el servidor. No necesitas instalar nada en tu ordenador.

1b. ¿Cuándo pasar de index.html a index.php?

Cuando empiezas un proyecto web, puedes usar index.html para crear una página estática. Pero en cuanto necesitas lógica de servidor — procesar un formulario, consultar la base de datos, mostrar datos dinámicos — hay que cambiar a index.php.

index.htmlindex.php
¿Lo ejecuta el servidor?No — se envía tal cual al navegadorSí — el servidor lo procesa antes de enviarlo
¿Puede conectarse a la DB?❌ No✅ Sí
¿Puede procesar formularios?❌ No✅ Sí
¿Puede mostrar datos dinámicos?❌ No✅ Sí

✅ Regla práctica Simplemente renombra el archivo de index.html a index.php cuando necesites añadir PHP. El servidor detecta la extensión y ejecuta el código PHP automáticamente. Los demás archivos HTML que no necesiten PHP pueden quedarse como .html.

<!DOCTYPE html>

3. Tipos de datos y operadores

<?php
// ── Tipos básicos ──
$cadena  = "Hola";          // string
$entero  = 42;              // integer
$decimal = 3.14;            // float
$booleano = true;           // boolean
$nulo    = null;            // null

// Comprobar el tipo
var_dump($cadena);    // → string(4) "Hola"
var_dump($entero);    // → int(42)
gettype($booleano);   // → "boolean"

// ── Conversión de tipos ──
$numero_str = "42";
$numero     = (int)$numero_str;      // → 42
$decimal2   = (float)"3.14abc";     // → 3.14
$texto      = (string)100;          // → "100"

// ── Operadores aritméticos ──
echo 10 + 3;   // → 13
echo 10 - 3;   // → 7
echo 10 * 3;   // → 30
echo 10 / 3;   // → 3.333...
echo 10 % 3;   // → 1 (módulo)
echo 2 ** 8;   // → 256 (potencia)

// ── Concatenación de strings con punto . ──
$nombre    = "Ana";
$apellido  = "García";
$completo  = $nombre . " " . $apellido;  // → "Ana García"

// Concatenar y asignar
$mensaje  = "Hola";
$mensaje .= ", mundo!";  // → "Hola, mundo!"

// ── Operadores de comparación ──
// == compara valor (con conversión de tipo)
// === compara valor Y tipo (recomendado)
var_dump(0 == "0");    // → true (loose comparison)
var_dump(0 === "0");   // → false (strict comparison: int vs string)
var_dump(0 != "a");    // → true
var_dump(0 !== "0");   // → true

var_dump(5 > 3);   // → true
var_dump(5 < 3);   // → false
var_dump(5 >= 5);  // → true

// ── Operadores lógicos ──
$a = true;
$b = false;

var_dump($a && $b);   // AND → false
var_dump($a || $b);   // OR  → true
var_dump(!$a);        // NOT → false
?>

4. Estructuras de control

<?php
// ── if / elseif / else ──
$nota = 7.5;

if ($nota >= 9) {
    echo "Sobresaliente";
} elseif ($nota >= 7) {
    echo "Notable";
} elseif ($nota >= 5) {
    echo "Aprobado";
} else {
    echo "Suspenso";
}

// Operador ternario (forma corta)
$estado = ($nota >= 5) ? "Aprobado" : "Suspenso";
echo $estado; // → "Notable" ... eh, "Aprobado"

// Null coalescing operator (??) — muy útil con formularios
$nombre = $_GET['nombre'] ?? 'Anónimo';
// Si $_GET['nombre'] existe y no es null → lo usa; si no → 'Anónimo'

// ── switch ──
$dia = "lunes";

switch ($dia) {
    case "lunes":
    case "martes":
    case "miércoles":
    case "jueves":
    case "viernes":
        echo "Día laborable";
        break;
    case "sábado":
    case "domingo":
        echo "Fin de semana";
        break;
    default:
        echo "Día no reconocido";
}

// ── for ──
for ($i = 1; $i <= 5; $i++) {
    echo "Iteración número $i <br>";
}

// ── foreach — el más usado para arrays ──
$frutas = ["manzana", "pera", "naranja", "uva"];

foreach ($frutas as $fruta) {
    echo "- $fruta <br>";
}

// Con índice:
foreach ($frutas as $indice => $fruta) {
    echo "$indice: $fruta <br>";
}

// ── while ──
$intentos = 0;
$maxIntentos = 3;

while ($intentos < $maxIntentos) {
    echo "Intento " . ($intentos + 1) . "<br>";
    $intentos++;
}

// ── do...while — se ejecuta al menos una vez ──
$numero = 0;
do {
    echo "Número: $numero <br>";
    $numero++;
} while ($numero < 3);
?>

5. Funciones

<?php
// ── Definición de función ──
function saludar($nombre, $saludo = "Hola") {
    // $saludo tiene valor por defecto
    return "$saludo, $nombre!";
}

echo saludar("Ana");              // → "Hola, Ana!"
echo saludar("Carlos", "Buenas"); // → "Buenas, Carlos!"

// ── Función que retorna múltiples valores (como array) ──
function dividir($dividendo, $divisor) {
    if ($divisor == 0) {
        return ["error" => "División por cero"];
    }
    return [
        "cociente"  => intdiv($dividendo, $divisor),
        "resto"     => $dividendo % $divisor
    ];
}

$resultado = dividir(17, 5);
echo "Cociente: " . $resultado['cociente']; // → 3
echo "Resto: "    . $resultado['resto'];    // → 2

// ── Type hints (PHP 7+) — declarar tipos de parámetros y retorno ──
function calcularIMC(float $peso, float $altura): float {
    return $peso / ($altura ** 2);
}

function obtenerSaludo(string $nombre): string {
    return "Hola, $nombre!";
}

// ── Funciones de string de PHP ──
$cadena = "  Hola, Mundo!  ";

echo strlen($cadena);            // → 16 (longitud)
echo strtolower($cadena);        // → "  hola, mundo!  "
echo strtoupper($cadena);        // → "  HOLA, MUNDO!  "
echo trim($cadena);              // → "Hola, Mundo!" (quita espacios)
echo str_replace(",", ";", $cadena); // → "  Hola; Mundo!  "
echo substr($cadena, 2, 4);      // → "Hola" (desde pos 2, 4 chars)
echo strpos($cadena, "Mundo");   // → 7 (posición de "Mundo")
echo str_word_count($cadena);    // → 2 (número de palabras)

// Funciones de número
echo round(3.567, 2);   // → 3.57 (redondear a 2 decimales)
echo ceil(4.1);         // → 5  (redondear arriba)
echo floor(4.9);        // → 4  (redondear abajo)
echo abs(-42);          // → 42 (valor absoluto)
echo rand(1, 100);      // Número aleatorio entre 1 y 100
?>

6. Arrays

<?php
// ── Array indexado ──
$colores = ["rojo", "verde", "azul"];
$colores[] = "amarillo"; // Añadir al final (equivale a array_push)

echo $colores[0];    // → "rojo"
echo count($colores); // → 4

array_push($colores, "morado");  // Añadir al final
array_unshift($colores, "negro"); // Añadir al principio
$ultimo = array_pop($colores);    // Quitar y devolver el último
$primero = array_shift($colores); // Quitar y devolver el primero

// Ordenar
sort($colores);   // Ordena ascendente (modifica el array original)
rsort($colores);  // Ordena descendente

// ── Array asociativo (clave => valor) ──
$usuario = [
    "nombre"   => "Ana García",
    "email"    => "ana@universidad.es",
    "edad"     => 22,
    "carrera"  => "Telecomunicaciones",
    "activo"   => true
];

// Acceder por clave
echo $usuario["nombre"];  // → "Ana García"
echo $usuario["email"];   // → "ana@universidad.es"

// Añadir / modificar
$usuario["telefono"] = "+34 600 000 000";
$usuario["edad"]     = 23;

// Comprobar si existe una clave
if (isset($usuario["telefono"])) {
    echo "Tiene teléfono: " . $usuario["telefono"];
}

// Eliminar clave
unset($usuario["activo"]);

// Claves y valores
$claves  = array_keys($usuario);   // ["nombre", "email", "edad", ...]
$valores = array_values($usuario); // ["Ana García", "ana@...", 22, ...]

// ── Array de arrays (bidimensional) — típico para datos de DB ──
$estudiantes = [
    ["nombre" => "Ana",    "nota" => 9.0],
    ["nombre" => "Carlos", "nota" => 7.5],
    ["nombre" => "María",  "nota" => 8.3],
];

// Recorrer con foreach
foreach ($estudiantes as $estudiante) {
    echo $estudiante["nombre"] . ": " . $estudiante["nota"] . "<br>";
}

// Ordenar por un campo
usort($estudiantes, fn($a, $b) => $b["nota"] <=> $a["nota"]);
// Ahora están ordenados de mayor a menor nota

// ── Funciones útiles de array ──
$numeros = [3, 1, 4, 1, 5, 9, 2, 6, 5];

$unicos  = array_unique($numeros);       // Elimina duplicados
$filtrados = array_filter($numeros, fn($n) => $n > 3); // Solo los > 3
$dobles  = array_map(fn($n) => $n * 2, $numeros);      // Multiplica por 2
$suma    = array_sum($numeros);          // → 36 (suma de todos)

var_dump(in_array(5, $numeros));        // → true (¿existe el valor?)
?>

7. Superglobales: $_GET, $_POST, $_SESSION

Las superglobales son arrays especiales de PHP accesibles en cualquier parte del código (sin necesidad de declarar como global). 

<?php
// ── $_GET: parámetros en la URL ──
// URL: http://localhost/buscar.php?termino=redes&pagina=2

$termino = $_GET['termino'] ?? '';  // → "redes"
$pagina  = (int)($_GET['pagina'] ?? 1);  // → 2

// ⚠️ SIEMPRE sanitizar antes de usar
$termino_seguro = htmlspecialchars($termino, ENT_QUOTES, 'UTF-8');
echo "Buscando: $termino_seguro en página $pagina";

// ── $_POST: datos enviados por formulario POST ──
// (Más seguro que GET para datos sensibles: no aparecen en la URL)
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $nombre   = trim($_POST['nombre']   ?? '');
    $email    = trim($_POST['email']    ?? '');
    $password = $_POST['password'] ?? '';

    // Validar
    if (empty($nombre)) {
        $errores[] = "El nombre es obligatorio";
    }
    if (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $errores[] = "Email no válido";
    }
    if (strlen($password) < 8) {
        $errores[] = "La contraseña debe tener al menos 8 caracteres";
    }

    if (empty($errores)) {
        // Procesar datos (guardar en BD, enviar email...)
        $password_hash = password_hash($password, PASSWORD_BCRYPT);
        echo "Formulario válido. Procesando...";
    }
}

// ── $_SESSION: guardar datos entre páginas ──
// ⚠️ Siempre llamar session_start() ANTES de cualquier output HTML
session_start();

// Guardar datos en la sesión (p.ej: al hacer login)
$_SESSION['usuario_id']    = 42;
$_SESSION['usuario_nombre'] = "Ana García";
$_SESSION['logueado']       = true;

// Leer datos de la sesión (en cualquier otra página)
if (isset($_SESSION['logueado']) && $_SESSION['logueado'] === true) {
    $nombre = $_SESSION['usuario_nombre'];
    echo "Bienvenida, $nombre!";
} else {
    header('Location: login.php');  // Redirigir a login
    exit; // Importante: detener ejecución después de header redirect
}

// Eliminar un dato de la sesión
unset($_SESSION['temporal']);

// Destruir la sesión completa (logout)
session_destroy();
?>

8. Incluir archivos: include y require

Para no repetir código (como la conexión a la base de datos o el header de la página), podemos separarlo en archivos e incluirlos donde se necesiten. 

<?php
// ── require: si el archivo no existe, el script FALLA (error fatal) ──
// Ideal para archivos críticos como la conexión a la BD
require 'config/database.php';        // Ruta relativa
require_once 'config/database.php';   // Solo incluye UNA vez (evita duplicados)

// ── include: si el archivo no existe, solo da un WARNING (el script continúa) ──
// Ideal para partes de la vista (cabecera, pie de página...)
include 'views/header.php';
include_once 'views/footer.php';

// Ejemplo: estructura típica de un archivo PHP con includes
?>

// config/database.php — Archivo de configuración de la BD

9. Buenas prácticas

⚠️ Nunca mostrar errores en producción Durante el desarrollo activa los errores para detectar bugs. En producción, desactívalos para no revelar información sensible del servidor. 
<?php
// ── Configuración de errores ──

// Desarrollo: mostrar todos los errores
ini_set('display_errors', 1);
ini_set('display_startup_errors', 1);
error_reporting(E_ALL);

// Producción: ocultar errores al usuario, guardar en log
ini_set('display_errors', 0);
ini_set('log_errors', 1);
ini_set('error_log', '/var/log/php/error.log');
error_reporting(E_ALL);

// ── Separar lógica de presentación ──
// ❌ MAL: HTML y lógica mezclados
echo "<?php
if(\$nota >= 5) {
    echo '<p style=\"color:green\">' . \$nombre . ' ha aprobado</p>';
} else {
    echo '<p style=\"color:red\">' . \$nombre . ' ha suspendido</p>';

?>";

// ✅ BIEN: lógica en PHP, HTML en la vista
