¿Cómo usar esta guía?

Cada sección es independiente pero se recomienda seguir el orden presentado, ya que los conceptos se van apoyando unos en otros. Todos los ejemplos de código son completos y ejecutables; puedes copiarlos directamente en tus archivos de práctica.

💡 Consejo Aprenderás mucho más si escribes el código tú mismo en lugar de copiar y pegar. Cometer errores y corregirlos es parte fundamental del proceso de aprendizaje.

Entorno de trabajo

📌 Infraestructura facilitada por la asignatura El servidor web y la base de datos ya están instalados y configurados en un servidor de la UAB. Vosotros solo necesitáis conectaros y empezar a programar.

Acceso al servidor (SSH)

El código vive en un servidor remoto de la UAB. Para editarlo cómodamente se recomienda usar VS Code con la extensión Remote SSH, que permite abrir la carpeta del servidor como si fuera local.

Herramienta Uso Cómo obtenerla
VS Code ⭐ recomendado Editor de código code.visualstudio.com
Remote - SSH ⭐ recomendado Extensión de VS Code para conectarse al servidor UAB por SSH y editar archivos remotos Marketplace de VS Code → buscar "Remote - SSH" (Microsoft)
MobaXTerm Cliente SSH alternativo con terminal integrado (Windows) mobaxterm.mobatek.net
Terminal / iTerm2 Acceso SSH desde línea de comandos: ssh usuario@servidor.uab.cat Incluido en macOS/Linux. Windows: usar PowerShell o WSL

Acceso a la base de datos

La base de datos PostgreSQL también está en el servidor remoto. Se recomienda gestionarla con la extensión de VS Code para no necesitar instalar nada adicional.

Herramienta Uso Cómo obtenerla
Database Client JDBC ⭐ recomendado Extensión de VS Code para explorar y consultar la DB PostgreSQL directamente desde el editor Marketplace de VS Code → buscar "Database Client JDBC"
psql Cliente oficial de PostgreSQL por terminal: psql -U usuario -d mi_bd Incluido en el servidor. Acceder vía SSH
pgAdmin 4 Interfaz gráfica completa para PostgreSQL (alternativa si preferís una app dedicada) pgadmin.org

Ruta de aprendizaje sugerida

  1. HTML — Aprende a estructurar contenido con etiquetas.
  2. CSS — Dale estilo y diseño a tu estructura HTML.
  3. JavaScript — Añade interactividad en el navegador.
  4. PHP — Lógica del servidor: procesa formularios y genera HTML dinámico.
  5. PostgreSQL — Aprende SQL y cómo conectar PHP a una base de datos.
  6. MVC — Organiza todo lo anterior en una arquitectura profesional.
  7. Seguridad — Aprende a proteger tu aplicación: SQL Injection, XSS, hashing.
  8. Buenas Prácticas — Escribe código limpio, mantenible y profesional.
  9. UML / ER — Diseña la estructura de tu DB antes de crear tablas.
  10. DevTools — Usa las herramientas del navegador para depurar tu web.
✅ Objetivo final Al terminar esta guía serás capaz de construir una aplicación web completa con interfaz de usuario, lógica de servidor y persistencia de datos en una base de datos relacional.
